# 125A Arporator V0.1 Static GUI Specification

Status: static product-design contract before VSTGUI implementation.

## Design goal

Arporator must feel immediately usable like a simple DAW arpeggiator, while exposing the deeper musical engine without turning into a programming matrix.

The interface therefore uses:
- always-visible global musical controls;
- an always-visible 32-step overview;
- one selected-step detail editor instead of six controls repeated 32 times;
- one compact Variate/Locks section;
- no chord-sequencer page;
- no modulation matrix;
- no hidden pages required for normal operation.

## Proposed editor size

Base logical size: **1180 x 680 px**

Supported UI scales:
- 100%
- 150%

The visual design should be usable at 100% and remain crisp/readable at 150%.

## Header

Height: approximately 72 px.

Left:
- authoritative 125A master logo from `challanger2000/125A-Branding`
- preserve geometry/proportions exactly

Centre-left:
- product name: **ARPORATOR**
- subtitle: **MUSICAL MIDI ARPEGGIATOR**

Right:
- small version text
- future DEMO badge location if the product becomes paid

## Global section

Top functional row, approximately y=82..190.

Primary controls:
- MODE
- RATE
- OCTAVES
- LENGTH
- GATE
- SWING

Secondary musical controls:
- HUMANIZE
- GROOVE
- STRUM
- EVOLVE

Pitch/trigger selectors:
- TRIGGER: RESTART / CONTINUE
- PITCH POLICY: CHORD ONLY / SCALE / CHROMATIC
- KEY
- SCALE

Hierarchy:
- MODE / RATE / LENGTH must be visually strongest;
- OCTAVES / GATE / SWING medium priority;
- HUMANIZE / GROOVE / STRUM / EVOLVE one coherent family;
- pitch-policy controls grouped rather than scattered.

## 32-step overview

Main centre panel, approximately y=205..455.

Layout:
- two rows of 16 steps;
- each step cell is directly clickable/selectable;
- pattern length 1..32 determines which cells are active;
- cells outside active Pattern Length are visibly dimmed and do not participate in playback.

Each cell shows only high-value overview information:
- step number;
- ON/OFF state;
- NOTE offset;
- compact velocity level indicator;
- Ratchet badge when >1x;
- Probability warning/indicator when <100%;
- Lock marker when the step is locked.

Do **not** place six miniature knobs in every step.

Playback:
- current step gets a clear moving playhead highlight;
- selected editing step uses a separate selection border so playback and selection cannot be confused.

## Selected-step editor

Bottom-left/centre panel, approximately y=470..635.

Title:
- `STEP 01` .. `STEP 32`

Controls:
- ON
- NOTE: -4 .. +4 arp-order positions
- VELOCITY
- GATE
- RATCHET: 1x .. 4x
- PROBABILITY
- OCTAVE: -2 .. +2
- LOCK

The selected-step panel is the only detailed per-step editor.

Changing selected step must update these controls without changing audio merely because selection changed.

## Variate / Locks section

Bottom-right panel.

Primary action:
- large **VARIATE** push button

Control:
- VARIATION AMOUNT

Dimension locks:
- RHYTHM
- NOTE
- VELOCITY
- GATE
- RATCHET
- PROBABILITY
- OCTAVE

Meaning:
- OPEN: Variate and Evolve may alter this dimension where applicable.
- LOCK: both Variate and Evolve must preserve this dimension.

Per-step LOCK overrides the dimension state and freezes that entire step for Variate/Evolve.

## Evolve UX

EVOLVE is a global 0..100% amount.

Behaviour:
- 0% is exactly neutral;
- stored pattern never changes;
- first four pattern cycles after a RESTART remain the exact stored pattern;
- later evolution changes only temporary playback properties;
- new RESTART resets the evolution phase;
- dimension locks and per-step locks are respected.

No separate Evolve page is required in V0.1.

## Visual language

Follow 125A standards:
- segmented faceplate/panels;
- restrained analogue-hardware material treatment;
- screws/shadows only where they support the product design;
- controls must remain readable and not become decorative clutter;
- use approved 125A rendered knobs where knobs are appropriate;
- use purpose-built compact VSTGUI step cells/buttons for the sequencer matrix;
- do not scale one low-resolution knob strip for every UI scale.

Recommended visual balance:
- hardware-inspired upper/global control area;
- clearer modern sequencer matrix in the centre;
- consistent 125A typography and panel depth throughout.

## Control behaviour

Mandatory:
- Ctrl + left-click resets every continuous/custom control to its real defined default;
- 0% = neutral/off for Humanize, Groove, Strum, Evolve, Variation Amount where applicable;
- disabled/out-of-pattern steps are visibly distinct;
- parameter automation/state recall must update visible controls;
- editor open/close must never alter MIDI state.

## Deliberate omissions

Do not add to the V0.1 main UI:
- chord-step sequencing;
- multi-track routing;
- giant modulation matrix;
- 32 copies of every parameter control;
- technical RNG/seed controls;
- hidden advanced page needed for ordinary use.
